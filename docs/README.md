# 調査記録の索引

2026年10月29日作成。調査の本文と記録を主題ごとにまとめる。

## 置き場所

| 場所 | 中身 | Git |
|---|---|---|
| `docs/<主題>/` | 主題ごとの本文。結論、方針、計画、手順の説明 | 管理する |
| `docs/reports/<日付>-<名前>/` | 1回の調査の記録。投入前計画、実使用設定、集計CSV、図、再現手順 | 管理する |
| `data/`、`results/`、`external/` | データセット、学習結果、上流リポジトリ | 管理しない（ローカル専用） |

新しい記録は次のように置く。

- 1回の調査は `docs/reports/<YYYYMMDD>-<名前>/` に置き、CSVを管理するときは `.gitignore` に例外行を加える。
- 主題の結論が変わったら `docs/<主題>/` の本文を更新し、この索引の「現状」と記録の表に1行加える。
- 新しい主題を始めるときは `docs/` の下にフォルダを作り、この索引に節を加える。
