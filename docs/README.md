## 置き場所

| 場所 | 中身 | Git |

新しい記録は次のように置く。

- 1回の調査は `docs/reports/<YYYYMMDD>-<名前>/` に置き、CSVを管理するときは `.gitignore` に例外行を加える。
- 主題の結論が変わったら `docs/<主題>/` の本文を更新し、この索引の「現状」と記録の表に1行加える。
- 新しい主題を始めるときは `docs/` の下にフォルダを作り、この索引に節を加える。

## 表面場の予測

**現状**：AirfRANS の翼表面の点だけで Cp と Cf を予測し、積分した Cl・Cd を CFD と比べる計画を立てた。比較用の簡単なモデル、スライスの可視化、体積場も学習させた場合との比較も計画に入れた。環境の検証として、標準ベンチマークで論文の値を再現する計画も立てた。標準ベンチマークでは、Elasticity で論文の値（相対L2 0.0064）に対し 0.00605 を得て、MPS の環境に大きな問題がないことを確かめた（学習1回、CPU に逃がした演算なし）。Airfoil は試走だけで見送った。AirfRANS では、縮小した公式コードの学習（VOL-01）が MPS で通った。表面だけのモデル（SURF-01）は、Cf を直接予測することで Cd の摩擦成分を正しく求められたが、Cd の圧力成分はどちらのモデルでも予測できていない。学習データを `full` に増やした SURF-02 では、Cl の誤差が中央値 3.3%、Cd が 19% まで下がった。同じパラメータ数の点ごとの MLP より、すべての指標で誤差が小さく、差の大部分は前縁の近くで生じる。乱数の種を変えた3回の学習でも、この差は種による揺れよりずっと大きい。体積場も学習した公式コードを同じデータと大きさで学習した VOL-02 は、Cl の誤差が SURF-02 より大きく（中央値 0.052 と 0.031）、Cd は摩擦成分が正解の30倍で予測できない。外挿のタスクでは、表面だけのモデルの Cp・Cl の誤差は内挿の2〜3倍になり、学習範囲から離れるほど大きくなる。公式の大きさ（隠れ次元256・8層・398エポック）では、公式の学習率 1e-3 だと学習が不安定になるが、5e-4 以下にすると Cl の誤差が中央値 2.0〜2.2%、Cd が 10〜11% まで下がる。改善の大部分は学習を長くして学習率を下げたことによるもので、モデルを大きくした効果は小さく、結論の向きは変わらない。同じ長い学習でも点ごとの MLP はほとんど良くならず、Transolver との差は広がった。AirfRANS での調査はここで区切り、総括を conclusions.md にまとめた。Cl・Cd を求めるだけなら、流れの条件と NACA のパラメータから直接予測するパラメータ回帰のほうがはるかに正確で、場を予測するモデルの利点は Cp・Cf の分布が分かることにある。表面だけの予測は論文の数値とは比較できない独自の設定。
