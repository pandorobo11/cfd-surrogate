# 調査記録の索引

2026年10月29日作成。調査の本文と記録を主題ごとにまとめる。

## 置き場所

| 場所 | 中身 | Git |
|---|---|---|
| `docs/<主題>/` | 主題ごとの本文。結論、方針、計画、手順の説明 | 管理する |
| `docs/reports/<日付>-<名前>/` | 1回の調査の記録。投入前計画、実使用設定、集計CSV、図、再現手順 | 管理する |
| `data/`、`results/`、`external/` | データセット、学習結果、上流リポジトリ | 管理しない（ローカル専用） |

新しい記録は次のように置く。

- 1回の調査は `docs/reports/<YYYYMMDD>-<名前>/` に置き、CSVを管理するときは `.gitignore` に例外行を加える。
- 主題の結論が変わったら `docs/<主題>/` の本文を更新し、この索引の「現状」と記録の表に1行加える。
- 新しい主題を始めるときは `docs/` の下にフォルダを作り、この索引に節を加える。

## 表面場の予測

**現状**：AirfRANS の翼表面の点だけで Cp と Cf を予測し、積分した Cl・Cd を CFD と比べる計画を立てた。比較用の簡単なモデル、スライスの可視化、体積場も学習させた場合との比較も計画に入れた。環境の検証として、標準ベンチマークで論文の値を再現する計画も立てた。標準ベンチマークでは、Elasticity で論文の値（相対L2 0.0064）に対し 0.00605 を得て、MPS の環境に大きな問題がないことを確かめた（学習1回、CPU に逃がした演算なし）。Airfoil は試走だけで見送った。AirfRANS では、縮小した公式コードの学習（VOL-01）が MPS で通った。表面だけのモデル（SURF-01）は、Cf を直接予測することで Cd の摩擦成分を正しく求められたが、Cd の圧力成分はどちらのモデルでも予測できていない。学習データを `full` に増やした SURF-02 では、Cl の誤差が中央値 3.3%、Cd が 19% まで下がった。同じパラメータ数の点ごとの MLP より、すべての指標で誤差が小さく、差の大部分は前縁の近くで生じる。表面だけの予測は論文の数値とは比較できない独自の設定。
