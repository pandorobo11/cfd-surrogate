## 前提と限界

- **縮小した設定。** Transolver はどれも隠れ次元128・5層・200エポックで、公式（隠れ次元256・8層・398エポック）より小さい。公式の大きさ（VOL-03）は実行していない。論文の値とは並べない。
- **表面だけの予測は独自の設定。** 翼面の点だけを入力に Cp と Cf を予測し、Cl・Cd は予測を翼面で積分して求める。論文の AirfRANS の指標（体積場と表面場を同時に学習）とは比較できない。
- **正解の Cf は数値微分の値。** OpenFOAM の出力ではなく、`airfrans` が体積メッシュの速度場から求めた壁面せん断応力による。公式の Cd も同じ方法なので、比較の基準としては揃っている。
- **予測は検証済みの流れの解ではない。** 学習範囲（`full` ではレイノルズ数 2.0×10⁶〜6.0×10⁶、迎角 −4.9°〜14.9°、NACA 4桁・5桁系）の外は外挿で、誤差が大きくなる。
- **学習は多くが1回。** 乱数の種を変えて確かめたのは SURF-02 と SURF-06（各3回）だけ。

## 結論

### 1. 環境

Mac mini の MPS で、Transolver の学習と推論は CPU に逃がす演算なしで動く。標準ベンチマークの Elasticity では、論文の値（相対L2 0.0064）に対し 0.00605 を得た。

### 2. 体積場から Cd を求めると摩擦が数十倍になる

公式コード（体積場と表面を同時に学習）で予測した速度場から Cd を求めると、摩擦成分が正解の30〜36倍になり、Cd は使えない（VOL-01、VOL-02）。壁に一番近い点（壁から約2e-6）の速度の誤差が一様流の25〜36%あり、その勾配から壁面せん断応力を求めるためで、学習データを4倍にしても直らなかった。表面の Cf を直接予測すれば、摩擦成分の誤差は中央値1〜4%になる（SURF-01、SURF-02）。

### 3. 表面だけの Transolver は Cp・Cf・Cl をよく予測するが、Cd は難しい

`full` で学習すると（SURF-02、3回の平均）、テストの中央値で Cp・Cf の相対L2誤差は4〜5%、Cl の相対誤差は3.1%、順位相関は0.998。Cd は18%で、誤差の大部分は圧力成分から来る。圧力抵抗は大きな圧力の力の差として残る小さな量で、Cp のわずかな誤差が大きく効く。学習データの量の効果は大きく、`scarce`（180ケース）では Cl 14.5%、Cd 89% だった。

### 4. 点どうしの情報のやり取りは、前縁で効いている

同じパラメータ数の点ごとの MLP（SURF-06）に比べ、Transolver は Cp・Cf の誤差が約7分の1、Cl が約半分、Cd が約3分の1。差は乱数の種による揺れよりずっと大きい。差の大部分は前縁の負圧のピークにあり、前縁の近く（翼弦の2%）を除くと差は1.2〜1.6倍まで縮む。Transolver の3層目では、多くの頭が前縁、上面の前半・後半、下面、後縁を別々のスライスに分けていた。ただし、スライスが精度に効いていることの因果は確かめていない。

### 5. 同じ条件なら、表面だけのモデルのほうが体積場のモデルより表面の量が正確

同じデータ（`full`）と同じ大きさで比べると、表面だけのモデル（SURF-02）は体積場も学習したモデル（VOL-02）より Cl の誤差が小さく（中央値 0.031 と 0.052）、Cd の圧力成分の誤差も小さい。この縮小した設定では、体積場の情報は表面の予測を良くしなかった。学習時間は49分と5時間、ピークメモリは2.8GBと14.7GBで、表面だけのモデルのほうが軽い。

### 6. 外挿では誤差が2〜3倍になる

レイノルズ数と迎角の外挿（SURF-03、SURF-04）では、Cp・Cl の誤差が内挿の2〜3倍になり、学習範囲から離れるほど大きくなる。レイノルズ数は低い側、迎角は高い側の Cd が特に悪い。迎角が高い側の Cd の誤差（約60%）は、翼弦全体に散らばった圧力抵抗の系統的な過大評価で、後縁の剥離や摩擦は主な原因ではなかった。Cp・Cf の分布がほぼ重なって見えても Cd が2倍になるケースがある。

### 7. Cl・Cd だけが欲しいなら、パラメータ回帰がはるかに正確

流れの条件と NACA のパラメータ（7つの値）から Cl・Cd を直接予測する小さな MLP（SURF-09〜12）は、どのタスクでも Transolver の表面モデルより誤差がはるかに小さい（`full` で Cl 0.56%、Cd 0.32%。外挿でも Cl・Cd とも1〜2%）。学習は1分未満。AirfRANS の Cl・Cd は7つの値のなめらかな関数なので、数百ケースで十分に近似できる。

### 8. Cl・Cd を損失に加えても割に合わない

Transolver の損失に、積分した Cl・Cd の誤差を加えると（SURF-13、SURF-14）、Cd の誤差は 7〜9% に下がるが、Cp・Cf・Cl の誤差が大きく上がる。Cd の標準偏差が小さいので、その誤差の勾配が場の損失より強く効くと見込む。Cd でもパラメータ回帰には遠く及ばない。

## 使い分けの見込み

| 欲しいもの | 向いている方法 | 理由 |
|---|---|---|
| NACA 系の Cl・Cd | パラメータ回帰 | 最も正確で、学習も推論も一瞬 |
| Cp・Cf の分布（前縁の負圧のピーク、剥離の位置） | 表面だけの Transolver | 分布の精度が点ごとの MLP より明確に高い。体積場のモデルより軽い |
| 体積の流れ場 | 公式の Transolver | 表面だけのモデルでは得られない。ただし壁での勾配（摩擦）は信頼できない |
| パラメータで表せない形状の Cl・Cd | 未確認 | 場を予測するモデルの本来の強みのはずだが、AirfRANS は NACA 系だけなので確かめていない |

## 未確認のこと

- 公式の大きさ（隠れ次元256・8層・398エポック）での結果（VOL-03 など）。
- NACA 系以外の形状への一般化。
- スライスが精度に効いていることの因果（スライスを壊したときの変化）。
- 点ごとの MLP の外挿（SURF-07、SURF-08）と `scarce`（SURF-05）。
- 力係数の損失の重みをさらに小さくする、場の学習のあとに加える、などの工夫。
